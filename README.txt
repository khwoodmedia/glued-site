GLUED WEBSITE MOCKUP

Files:
- index.html
- archives.html
- styles.css
- script.js

How to use:
1. Unzip the folder.
2. Open index.html in a browser.
3. Replace the placeholder links marked href="#" with your real store, events and social links.
4. To use your real magazine artwork, replace the CSS-built cover inside .magazine-front with an <img> element or set a background image.

Publishing:
This static site can be uploaded directly to Netlify, GitHub Pages, Squarespace custom code hosting or any standard web host.
